# kid-synth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single HTML file that turns an Akai MPK mini into a calm sound-and-picture toy for a 13-month-old.

**Architecture:** One hand-written `index.html`. An inline `<script id="core">` holds pure functions (MIDI bytes → action, knob position → note, hit strength → loudness) that Node tests load straight out of the HTML. A second inline script owns Web Audio, the canvas, Web MIDI and pointer input. Animal clips live in the file as base64 between two marker comments, written by a small Python script.

**Tech Stack:** Plain HTML/CSS/JS, Web Audio, Web MIDI, Canvas 2D. Node 26 `node:test` for tests. Python 3 and ffmpeg for preparing clips. No dependencies.

**Spec:** `docs/superpowers/specs/2026-11-14-kid-synth-design.md`

## Global Constraints

- The running app is `index.html` alone: no network requests, no external files, no build step.
- Every clip is CC0 or public domain, from Wikimedia Commons or BigSoundBank, and listed in `CREDITS.md` with author, source URL and licence.
- Pads: notes 23–30 (bank A) and 31–38 (bank B) → animal index `(note − 23) % 8`, on any channel.
- Knobs: controllers 1–8 → knob index `cc − 1`, value 0–127.
- Keys: every other note. Default range 48–72.
- At most 8 key voices, at most 2 animal clips at once.
- Loudness: hit strength 1–127 maps to gain 0.55–0.8, never outside. Master chain ends in a limiter; output peak stays at or below −3 dBFS.
- Calm: no element changes brightness faster than 150 ms in; key blooms fade over about 2 s; nothing animates without input.
- Work on branch `toddler-synth`. Commit after each task. Do not push.

## Review Focus

1. Keyboard unplugged and plugged back in mid-session → it plays again without a reload, and no note is left sounding.
2. Note-on with velocity 0 (the device's other way to say note-off), or a note-off that never arrives → the note stops; nothing drones.
3. A knob spun fast or jittering by ±1 at rest → no sound at rest, and a fast spin plays a run of notes rather than a wall of them.
4. A pad hammered many times a second → the clip restarts, loudness does not stack, never more than two animals.
5. No Web MIDI, or permission refused → the page says so in one plain sentence and the on-screen keys, pads and knobs still play.

## File Structure

| File | Responsibility |
|------|----------------|
| `index.html` | The whole app |
| `test/core.test.mjs` | Loads `<script id="core">` from `index.html`, tests the pure functions |
| `test/clips.test.mjs` | Checks the embedded clip block and `CREDITS.md` |
| `tools/embed-sounds.py` | Encodes `sounds/*.ogg` into the marker block of `index.html` |
| `sounds/` | The eight prepared clips, `0-cow.ogg` … `7-frog.ogg` |
| `CREDITS.md` | One row per clip |
| `README.md` | What it is, the one-line serve command, how to swap a clip |

### Task 1: Core logic

**Files:**
- Create: `index.html` (skeleton with `<script id="core">`), `test/core.test.mjs`

**Interfaces:**
- Produces, all defined in `<script id="core">` as plain function declarations:
  - `route(bytes: number[]) → Action | null`, where Action is one of
    `{type:'key', note, on:boolean, vel}`, `{type:'pad', index}`,
    `{type:'knob', index, value}`, `{type:'bend', value}` (value −1…1)
  - `velGain(vel: number) → number`
  - `knobNote(index: number, value: number) → number` (MIDI note)
  - `ANIMALS: {name, emoji}[]` in pad order: cow, sheep, cat, dog, duck, rooster, horse, frog

- [ ] **Step 1: Write the failing tests** in `test/core.test.mjs`. The loader reads `index.html`, takes the text of `<script id="core">`, and evaluates it with `new Function(src + '; return {route, velGain, knobNote, ANIMALS}')`.

```js
test('key down and up', () => {
  assert.deepEqual(route([0x90, 60, 100]), {type:'key', note:60, on:true, vel:100});
  assert.deepEqual(route([0x80, 60, 0]),   {type:'key', note:60, on:false, vel:0});
});
test('note-on with velocity 0 is a key up', () => {
  assert.deepEqual(route([0x90, 60, 0]), {type:'key', note:60, on:false, vel:0});
});
test('pad notes on both banks and any channel', () => {
  assert.deepEqual(route([0x90, 23, 90]), {type:'pad', index:0});
  assert.deepEqual(route([0x90, 30, 90]), {type:'pad', index:7});
  assert.deepEqual(route([0x99, 31, 90]), {type:'pad', index:0});
  assert.deepEqual(route([0x90, 38, 90]), {type:'pad', index:7});
});
test('pad release makes nothing', () => {
  assert.equal(route([0x80, 23, 0]), null);
  assert.equal(route([0x90, 23, 0]), null);
});
test('program change plays an animal', () => {
  assert.deepEqual(route([0xC0, 9]), {type:'pad', index:1});
});
test('knobs', () => {
  assert.deepEqual(route([0xB0, 1, 0]),   {type:'knob', index:0, value:0});
  assert.deepEqual(route([0xB0, 8, 127]), {type:'knob', index:7, value:127});
  assert.equal(route([0xB0, 64, 127]), null);
});
test('pitch bend', () => {
  assert.equal(route([0xE0, 0, 64]).value, 0);
  assert.equal(route([0xE0, 0, 0]).value, -1);
  assert.ok(Math.abs(route([0xE0, 127, 127]).value - 1) < 0.001);
});
test('junk is ignored', () => {
  for (const b of [[], [0xF8], [0x90], [0x90, 60], [0xF0, 1, 2, 0xF7]]) assert.equal(route(b), null);
});
test('loudness stays in a narrow band', () => {
  assert.equal(velGain(1), 0.55);
  assert.equal(velGain(127), 0.8);
  assert.equal(velGain(999), 0.8);
  assert.equal(velGain(-5), 0.55);
});
test('knobs play a five-note scale', () => {
  const pc = new Set([0, 2, 4, 7, 9]);
  for (let k = 0; k < 8; k++) for (let v = 0; v <= 127; v++) assert.ok(pc.has(knobNote(k, v) % 12));
  assert.ok(knobNote(0, 127) > knobNote(0, 0));
  assert.equal(knobNote(0, 60), knobNote(0, 61));   // ±1 jitter stays on the same note
  assert.equal(ANIMALS.length, 8);
});
```

### Task 3: Sound engine

**Files:**
- Modify: `index.html` (second inline script)

**Interfaces:**
- Consumes: `route`, `velGain`, `knobNote`, `CLIPS`.
- Produces: `window.kid` with `start() → Promise<void>` (creates the AudioContext, decodes the clips), `handle(bytes: number[]) → void` (the single entry point for every input source), `allOff() → void`, `setVolume(0…1)`, and read-only `state: {keys: Set<number>, clipsPlaying: number, knobs: number[8], peak: number}` where `peak` is the highest absolute sample seen at the output since start.

- [ ] **Step 1: Implement the key voice.** Two detuned triangle oscillators plus a sine one octave up, through a low-pass at 2.2 kHz; 8 ms attack, decays to 35 % over 1.2 s while held, 250 ms release. Ninth note steals the oldest. Pitch bend moves all held notes by up to ±2 semitones.
- [ ] **Step 2: Implement the clip player.** Hitting a pad that is playing stops that clip with a 20 ms fade and restarts it. A third animal fades out the oldest.
- [ ] **Step 3: Implement the knob voices.** A knob sounds only when its `knobNote` changes, and at most once per 70 ms per knob. Eight short plucked voices, 0.3–0.8 s long, differing in waveform and decay: music box, marimba, water drop, soft bell (top row), kalimba, wood block, bubble, low bell (bottom row).
- [ ] **Step 4: Implement the master chain.** Sum → gain 0.7 (the parent's volume scales this) → `DynamicsCompressorNode` (threshold −14 dB, ratio 12, attack 3 ms) → analyser feeding `state.peak` → destination.
- [ ] **Step 5: Verify in the built-in browser** over `python3 -m http.server 8377`. After one click, run in the page:

```js
await kid.start();
for (let n = 48; n < 60; n++) kid.handle([0x90, n, 127]);     // 12 keys at full strength
for (let i = 0; i < 40; i++) kid.handle([0x90, 23 + i % 8, 127]); // hammer the pads
for (let v = 0; v < 128; v++) kid.handle([0xB0, 1, v]);        // spin a knob
await new Promise(r => setTimeout(r, 1500));
[kid.state.keys.size, kid.state.clipsPlaying, kid.state.peak]
```

Expected: `keys.size` is 8, `clipsPlaying` is 2, `peak` is above 0.05 and at or below 0.708 (−3 dBFS). Then `kid.handle([0x90,60,0])`-style releases and `kid.allOff()` bring `keys.size` to 0, and `kid.handle([0xB0,1,64]); kid.handle([0xB0,1,65])` after a pause changes nothing audible (same `knobNote`).
- [ ] **Step 6: Commit** `feat: sound engine`.
